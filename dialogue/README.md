# Dialogue studio

Start at `works/<project>/SESSION-START.md`. From that project directory, the
framework is reached as `../../PLAYBOOK.md`, `../../PROMPTING.md`, and
`../../tools/`. The session entry routes a fresh orchestrator to the project's
owner-controlled script, intent source, approved references, and current
handoff. `PLAYBOOK.md` is the canonical lifecycle; `PROMPTING.md` governs
builder-only prompt writing.

`templates/project/` is the copyable project skeleton. `templates/roles/` contains executable role packets. `templates/gates/` contains bounded milestone and release gates. `tools/` performs only mechanical assembly, preflight, report validation, candidate checks, and retry routing. `case-studies/` is evidence, never authority.

The transport invariant is simple: a critic sees a neutral candidate/proof capsule, then exact script + page intent + numbered card. It never sees a generation prompt, builder audit, references, version, or history.
