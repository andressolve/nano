# Fresh reference-system critic

Use a zero-history context. Stage 1 reads neutral cast/reference artifacts as a
system: lineups, face crops, profiles, silhouettes, grayscale, varied light,
reactions, age/disguise states, and hard live pairings. Stage 2 opens only the
casting ledger, setting/object ledger, reference plan, numbered gate, and lock
manifest. Judge identity separation and consequential continuity, not costume
minutiae. Bind the exact allowlisted input capsule in `REFERENCE-REPORT.md`;
approve only with no failure language and `NONE` findings. The manifest owner
cannot fill this critic role. Never read generation prompts, audits, rejected
history, or edit/promote artifacts.
