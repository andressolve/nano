blind-read the 600x900 proof: state event, dramatic owner, turn, and every
visible string with attribution. Then open `authority.md`, containing only
exact owner script, page intent, and numbered card. Write the neutral

`VERDICT: REVISE`; a revision must use one card criterion and concrete

prompt, audit, refs, version, history, or rejected candidates.
