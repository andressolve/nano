# One-page packet builder

Read one exact full-script page block, its page-contract block, locked visual
direction, and the approved page binding map. Write only that page's reader
intent, builder-only generation prompt, and numbered critic card. Bind source
hashes; copy every exact script string and owner into the prompt once. Keep
intent free of generation instructions and card free of prompts, audits,
references, versions, history, rejected art, numeric type, and panel-share
criteria. Do not open neighboring pages except one compact continuity fact
explicitly required by the current contract.
