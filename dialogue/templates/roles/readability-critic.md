# Fresh complete-script readability critic

Use a zero-history context. Read the complete script in order and its matching
page contract. First record a normal reader's plain-language account; then
check causality, character knowledge, body/time/travel/document/object
mechanics, dialogue aloud, speaker presence/order, emotional duration, density,
and every page turn. “Recoverable after rereading” is `REVISE`. Bind the exact
script and contract inside the byte-bound input-capsule receipt in
`READABILITY-REPORT.md`; approve only with every page `PASS`, no failure
language, and findings exactly `NONE`. The manifest owner cannot fill this
critic role. Do not read builder transcripts,
references, generation prompts, sources, or fidelity notes.
