## Protocol

The Pages 11–20 batch uses the same two-gate pattern proven on *The Lake City*
and the approved Monte Cristo opening:

1. **Critic 1 — script/image fidelity.** Reads the approved script, identity
   authorities, mandates, canonical full-size pages, and mobile proofs. It does
   not read producer QA or rejected images. It checks exact text, panel map,
   speaker lanes, tails, silent roles, props, identities, dimensions, and
   causal staging.
2. **Critic 2 — blind cold read and visual defects.** Reads only the 390 × 585
   proofs first, then the full-resolution pages, and consults the script and
   identity ledger only after recording the blind read. It checks effortless
   comprehension, actual-size lettering, anatomy, hands, limbs, faces, bodies,
   duplication, props, borders, balloons, tails, identities, and continuity.

Both gates must issue an unconditional pass. A recoverable inference is not a
pass. Every blocking repair is a complete versioned page regeneration; no
balloon, face, tail, word, or panel patch is permitted.
