# The Invisible Forces — Production Plan

## Purpose

This document turns the design package into a generation-ready production workflow.

It does **not** start image generation. It locks the production assumptions, classifies the pages by difficulty and type, defines the first-wave reference assets, and sets the go/no-go standard for beginning image work.

## Locked Assumptions

These are the default assumptions unless later prototypes prove they need revision.

- **Title direction:** keep `The Invisible Forces` as the working title for Book One
- **Subtitle direction:** keep `Isaac Newton, Book One` as the working subtitle; this can be sharpened later without affecting production
- **Working length:** keep the current `24 total pages` structure as the production baseline
- **Page-count flexibility:** pages may still expand or compress if hard-page prototypes prove that necessary
- **Barrow:** keep out of first-wave production; use only if page 7 or 16 needs an additional human counterweight
- **Coda page:** keep page 24 for now; it gives the book room to end in a human register rather than at pure conceptual climax
- **Book boundary:** nothing from Hooke/Leibniz priority wars, Mint politics, old-age celebrity, or full public Newton should enter Book One except the faintest tonal foreshadowing
- **Merge candidate if necessary:** page 19 is the cleanest page to compress into page 18 if a later science split is required

## Complexity Notes

- **Narrative pages** are mainly about emotional and historical clarity.
- **Bridge pages** are structurally important but visually simpler. They carry transitions, pacing, and tone.
- **Science pages** are the primary production risk. They must remain image-native and conceptually honest.
- **xhigh pages** are the ones that can force structural revision if they fail repeatedly.

### Why This Order

- Pages 10 and 11 determine whether the optics argument can be trusted visually.
- Pages 14 and 15 determine whether gravity can be shown honestly rather than decoratively.
- Page 23 determines whether the book has a viable climax.
- Page 12 is conceptually hard but can be simplified more than the others if needed.
- Page 17 tests object fidelity and engineering plausibility.

## Review Criteria

Every accepted page should pass these five checks:

1. **Identity continuity**
The correct Newton age phase appears, and supporting characters still match their refs.

2. **Period/material plausibility**
Rooms, clothing, paper, tools, and objects feel materially 17th century.

3. **Composition clarity**
The main action or argument of the page reads immediately.

4. **Text discipline**
No tiny unreadable lettering. No more text than the image can credibly carry.

5. **Scientific honesty**
The page does not fake understanding through atmosphere alone. The experiment, inference, or consequence is visible and graspable.

- If a new attempt is only exploratory, do not overwrite an accepted page.
- If a replacement clearly wins, archive the old final before replacing it.

## Go / No-Go Standard For Starting Image Generation

**GO** only when all of the following are true:

- First-wave Newton references are locked
- Woolsthorpe chamber and prism object logic are visually locked
- At least one viable composition exists for pages 10, 11, 14, 15, and 23
- No prototype page still depends on dense tiny labels to make sense
- The book still feels coherent at the current page count after prototype review

**NO-GO** if any of the following remains true:

- The second-prism page still reads like decorative rainbow imagery rather than proof
- The moon-falling page still reads mystical instead of physical
- The inverse-square page cannot be made intelligible without textbook clutter
- The final synthesis page still looks bombastic but conceptually vague
- Newton's age continuity is unstable across the first-wave refs

## Expected Revisions After Prototype Pass

The most likely structural adjustments are:

- splitting page 12 if fluxions remains too compressed
- compressing page 19 into page 18 if science pages need more room
- reducing in-image text and letting more explanation move into captions
- simplifying page 23 if the unified-climax composition becomes overstuffed
